DATENVERBINDUNG

Apple Health → FORGE

Ohne Server

Über die iPhone-App „Kurzbefehle“ kannst du Schritte und Gewicht aus Health an FORGE übergeben, ohne jeden Wert abzutippen. Der Übertragungslink verwendet nur einen URL-Fragmentteil: Deine Messwerte werden dabei nicht an GitHub Pages gesendet.

Letzte ÜbernahmeNoch nieNoch keine Daten aus einem Kurzbefehl
Kurzbefehle einrichten
  1. Erstelle auf deinem iPhone in Kurzbefehle einen neuen Kurzbefehl.
  2. Lies über Health-Messungen suchen deine Schritte für heute aus und summiere sie. Optional: Suche das letzte Körpergewicht in kg.
  3. Füge die ermittelten Werte in die Platzhalter DATUM, SCHRITTE und optional GEWICHT des Links ein. Für das Datum das Format yyyy-MM-dd verwenden.
  4. Öffne den fertigen Link mit der Aktion URLs öffnen. FORGE fragt vor der Speicherung um Bestätigung.

Die Health-Berechtigungen bleiben bei Apple Kurzbefehle. Das Öffnen kann Safari statt der installierten Web-App starten; Daten liegen jeweils lokal im verwendeten Browser. Eine automatische unsichtbare Cloud-Synchronisierung ist das nicht.

Garmin Connect

Garmin-Daten kannst du weiterhin als passend formatierte CSV importieren. Für eine automatische Garmin-Verbindung wäre ein sicherer Server erforderlich; einen privaten Garmin-API-Schlüssel niemals in diese öffentliche Web-App einfügen.

ERINNERUNGEN AUSSERHALB DER APP

iPhone-Kalendererinnerungen

Lade einen Kalenderplan für Wiegen, Kreatin und einen kurzen Schrittcheck herunter. Nach dem Import in deinen Kalender können dich Kalender-Benachrichtigungen erinnern, auch wenn FORGE geschlossen ist.

Der Download fügt keine Termine heimlich hinzu – du bestätigst den Import in deiner Kalender-App. Die Anzeige von Benachrichtigungen hängt von den iPhone-Kalendereinstellungen ab. Bei unregelmäßigen Schlafzeiten kannst du alternativ einen Kurzbefehl beim Ausschalten des Weckers ausführen lassen.

FORGE als iPhone-App

Öffne FORGE in Safari und wähle „Teilen“ → „Zum Home-Bildschirm“. Die App kann danach eigenständig starten und zuvor geladene Inhalte offline anzeigen. Wichtig: Exportiere zuvor ein Backup, falls deine Safari-Einträge in der installierten Web-App nicht erscheinen.

Gespeicherte Werte bleiben lokal in deinem Browser. Nutze das Backup bei Gerätewechsel.
